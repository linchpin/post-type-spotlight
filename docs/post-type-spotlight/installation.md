# Installation

## From WordPress.org

1. In the WordPress admin, go to **Plugins → Add New**.
2. Search for **Post Type Spotlight**.
3. Install and activate.

## Manually

1. Download the plugin zip from
   [wordpress.org/plugins/post-type-spotlight](https://wordpress.org/plugins/post-type-spotlight/)
   or from a [GitHub release](https://github.com/linchpin/post-type-spotlight/releases).
2. Upload the folder to `/wp-content/plugins/`.
3. Activate through the **Plugins** menu.

## Requirements

| Requirement | Version |
| --- | --- |
| WordPress | 5.9 or later |
| PHP | 7.4 or later |

## After activating

Nothing is featured until you choose which post types can be. Go to
**Settings → Writing** and tick the post types you want, under **Featured Post
Types**. See [Usage](usage.md).
